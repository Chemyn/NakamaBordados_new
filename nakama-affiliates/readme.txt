Programa de afiliados de Nakama Bordados: perfiles, códigos exclusivos,
atribución, comisiones, cierres y beneficios mensuales.

== Installation ==

1. Instala y activa WooCommerce.
2. Sube la carpeta `nakama-affiliates` a `wp-content/plugins`.
3. Activa “Nakama Afiliados” desde WordPress.

La facturación automática y el cálculo fiscal automático no forman parte de
esta versión.

== Data retention ==

Desinstalar conserva los datos por defecto. La purga irreversible solo se
ejecuta cuando `NAKAMA_AFFILIATES_PURGE_DATA` está definida como el booleano
`true` antes de desinstalar desde WordPress.
